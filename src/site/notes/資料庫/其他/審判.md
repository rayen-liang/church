# 審判:
##### *英文名稱 :* Judgment
#概念 #審判

----------------------------------------------------
### 簡介:
- 在[[資料庫/其他/聖經\|聖經]]中指[[資料庫/其他/神\|神]]按公義與各人所行的行為施行裁決、賞善罰惡的作為，包含歷史中的時代審判（如[[資料庫/人物/挪亞\|挪亞]]時期的[[資料庫/事件/洪水事件\|洪水]]）與末後的審判。
- 本知識庫話語資料亦指出，[[資料庫/其他/神\|神]]會按照人的行為回報與審判，並藉[[資料庫/其他/真理\|真理]]話語分辨是非。
