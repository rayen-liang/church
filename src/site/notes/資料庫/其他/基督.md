# 基督:
##### *英文名稱 :* Christ
#概念 #基督

----------------------------------------------------
### 簡介:
- 源自希臘文 *Christos*，意為「受膏者」，對應希伯來文的「彌賽亞」（*Messiah*）。
- 在新約[[資料庫/其他/聖經\|聖經]]中為[[資料庫/人物/耶穌\|耶穌]]的尊稱，指[[資料庫/其他/神\|神]]所差遣、受膏承擔救贖使命的救主。
