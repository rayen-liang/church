# 復活:
##### *英文名稱 :* Resurrection
#概念 #復活

----------------------------------------------------
### 簡介:
- 在[[資料庫/其他/聖經\|聖經]]與基督教信仰中，指從死亡中重新活過來，核心包含[[資料庫/人物/耶穌\|耶穌]]的復活以及信徒脫離死亡進入生命的盼望。
- 在本知識庫的話語資料（如[[話語/主日話語/2026/260816-不速之客\|260816-不速之客]]）中，特別從屬靈角度詮釋復活，強調心靈與靈魂透過相信並實踐[[資料庫/其他/真理\|真理]]而從死亡圈進入生命圈；關於復活的詮釋在基督教不同傳統間存在不同說法。
