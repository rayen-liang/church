# 撒但:
##### *英文名稱 :* Satan
#概念 #撒但

----------------------------------------------------
### 簡介:
- 源自希伯來文 *Satan*，意為「敵對者」、「控告者」。
- 在[[資料庫/其他/聖經\|聖經]]中指抵擋[[資料庫/其他/神\|神]]旨意、試探與控告世人的惡者，新約亦常與[[資料庫/其他/魔鬼\|魔鬼]]並列或互稱。
- 在本知識庫的話語資料中，常提醒信徒分辨並防備撒但的誘惑與非[[資料庫/其他/真理\|真理]]，並藉由學習與實踐[[資料庫/其他/真理\|真理]]得勝。
