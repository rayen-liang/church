# 聖經:
##### *英文名稱 :* Bible
#概念 #聖經

----------------------------------------------------
### 簡介:
- 基督教的核心經典，由《舊約》39 卷與《新約》27 卷、共 66 卷書組成，記載[[資料庫/其他/神\|神]]的創造、[[資料庫/人物/以色列\|以色列]]歷史、先知預言、[[資料庫/人物/耶穌\|耶穌]][[資料庫/其他/基督\|基督]]生平與使徒書信等內容。
- 本知識庫已將全部 66 卷經文整理於 `分卷聖經/`（含[[分卷聖經/舊約/舊約\|舊約]]與[[分卷聖經/新約/新約\|新約]]總目錄），作為人物、事件與話語查考的原始依據。
