# 聖靈:
##### *英文名稱 :* Holy Spirit
#概念 #聖靈

----------------------------------------------------
### 簡介:
- 在[[資料庫/其他/聖經\|聖經]]與基督教信仰中，指[[資料庫/其他/神\|神]]的靈、保惠師，與[[資料庫/其他/神\|神]]一同動工，並引導、教訓、感動信徒明白[[資料庫/其他/真理\|真理]]與話語。
- 在本知識庫的話語資料中，亦常記載聖靈透過[[資料庫/其他/啟示\|啟示]]、感動與話語引導並幫助信徒實踐信仰。
