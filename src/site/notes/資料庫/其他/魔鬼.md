# 魔鬼:
##### *英文名稱 :* Devil
#概念 #魔鬼

----------------------------------------------------
### 簡介:
- 源自希臘文 *Diabolos*，意為「控告者」、「毀謗者」。
- 在新約[[資料庫/其他/聖經\|聖經]]中指抵擋[[資料庫/其他/神\|神]]、試探[[資料庫/人物/耶穌\|耶穌]]與信徒的邪惡勢力，常與[[資料庫/其他/撒但\|撒但]]並稱或同指。
