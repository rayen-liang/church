# 真理:
##### *英文名稱 :* Truth
#概念 #真理

----------------------------------------------------
### 簡介:
- 在[[資料庫/其他/聖經\|聖經]]與基督教信仰中，指永恆不變、真實無誤的[[資料庫/其他/神\|神]]的話語與法則；[[資料庫/人物/耶穌\|耶穌]]亦宣告「我就是道路、真理、生命」。
- 在本知識庫的話語資料中，強調唯有透過學習、體會並實踐真理，才能分辨是非、脫離無知與非真理，走向生命之路。
