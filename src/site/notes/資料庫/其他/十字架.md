# 十字架:
##### *英文名稱 :* Cross
#概念 #十字架

----------------------------------------------------
### 簡介:
- 原為古羅馬時期處決罪犯的刑具；在新約[[資料庫/其他/聖經\|聖經]]與基督教信仰中，因[[資料庫/人物/耶穌\|耶穌]][[資料庫/其他/基督\|基督]]被釘死於十字架上，成為犧牲、苦難與救贖的重要象徵。
- 新約亦以「背起十字架」比喻跟隨[[資料庫/人物/耶穌\|耶穌]]所需承擔的使命與代價。
