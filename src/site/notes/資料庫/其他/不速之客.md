# 不速之客:
##### *英文名稱 :* Uninvited Guest
#概念 #不速之客

----------------------------------------------------
### 簡介:
- 本知識庫主日話語[[話語/主日話語/2026/260816-不速之客\|260816-不速之客]]之核心主題詞，指如同不請自來的人一般，佔用並奪走人與[[資料庫/其他/神\|神]]、[[資料庫/其他/聖靈\|聖靈]]同行之「黃金時間」的一切人事物。
- 依該篇話語內容，包含帶來負擔的無謂承諾、睡眠與雜念、非必要的雜事與玩樂、自我合理化、非[[資料庫/其他/真理\|真理]]，以及[[資料庫/其他/撒但\|撒但]]、鬼與閒雜人等；話語教導應徹底分辨並剪除不速之客，專注於生命之路。
